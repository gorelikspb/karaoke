# 🎤 Караоке-сайт

Простой сайт для караоке, где можно найти тексты песен и петь под музыку.

## 🚀 Демо

**Статус:** В разработке (локальный проект)

## 📋 Описание

Этот сайт предоставляет:
- Тексты популярных песен
- Встроенные YouTube видео для прослушивания
- **Синхронизацию текста с музыкой** - слова подсвечиваются во время воспроизведения
- Удобный интерфейс для чтения текста во время пения

## 🎵 Как использовать

1. Откройте главную страницу
2. Выберите песню из списка
3. Включите видео - слова будут автоматически подсвечиваться во время воспроизведения
4. Пойте вместе с текстом!

## ⚠️ Важно

Музыка предоставляется через YouTube. Если видео недоступно в вашем регионе, попробуйте включить песню из другого источника.

## 🛠️ Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- YouTube IFrame API (для синхронизации)
- Система синхронизации текста с музыкой

## 📝 Добавление новых песен

1. Создайте новый HTML файл в папке `public/songs/`
2. Используйте шаблон из существующих песен (например, `song1.html`)
3. Добавьте ссылку на песню в `index.html`
4. **Добавьте тайминги для синхронизации:**
   - Найдите караоке-версию на YouTube (поиск: "название песни karaoke")
   - Создайте массив `words` с таймингами для каждого слова
   - Формат: `{text: "слово", start: время_начала, end: время_конца}` (время в секундах)

### Как найти караоке-версии на YouTube:

1. Откройте YouTube
2. Поиск: `"[название песни] karaoke"` или `"[название песни] instrumental"`
3. Выберите видео с хорошим качеством и четким звуком
4. Скопируйте ID видео из URL (например, из `youtube.com/watch?v=VIDEO_ID`)
5. Используйте этот ID в коде: `const videoId = 'VIDEO_ID';`

### Пример добавления таймингов:

```javascript
const songLyrics = {
    words: [
        {text: "Imagine", start: 3.0, end: 3.5},
        {text: "there's", start: 3.5, end: 3.8},
        {text: "no", start: 3.8, end: 4.0},
        // ... и так далее для каждого слова
    ]
};
```

**Совет:** Для точной синхронизации можно использовать инструменты вроде Audacity или онлайн-редакторы для определения времени начала каждого слова.

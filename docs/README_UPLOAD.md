# Инструкция по загрузке видео на YouTube

## Структура файлов

1. **video-metadata.json** - JSON файл со всеми метаданными для всех видео
2. **video_metadata/** - Папка с отдельными текстовыми файлами для каждого видео (создается скриптом)

## Создание файлов метаданных

Запустите скрипт для создания отдельных файлов:

```powershell
.\create-metadata-files.ps1
```

Или используйте Python скрипт напрямую:

```powershell
python create-metadata-files.py
```

**Примечание:** Используется Python скрипт для правильной работы с кириллицей в UTF-8.

Это создаст файлы вида `video_metadata/metadata_[название].txt` для каждого видео.

## Использование метаданных при загрузке

### Через YouTube Studio (веб-интерфейс):

1. Зайдите на https://studio.youtube.com
2. Нажмите "Создать" → "Загрузить видео"
3. Выберите скачанное видео из папки `downloaded_videos/`
4. Откройте соответствующий файл из `video_metadata/`
5. Скопируйте:
   - **TITLE** → в поле "Название"
   - **DESCRIPTION** → в поле "Описание"
   - **TAGS** → в поле "Теги" (через запятую)
   - **CATEGORY** → выберите категорию "Музыка"

### Через YouTube API (программно):

Можно использовать файл `video-metadata.json` для автоматической загрузки через API.

## Важные моменты

⚠️ **Перед загрузкой проверьте:**
- Все права на использование контента соблюдены
- Видео не нарушает авторские права
- Описание и теги соответствуют содержанию

✅ **Рекомендации:**
- Добавьте в описание ссылку на ваш сайт
- Используйте правильные теги для лучшей индексации
- Установите возрастные ограничения при необходимости
- Выберите правильную категорию (Музыка)

## Структура файла метаданных

Каждый файл содержит:
- **TITLE** - название видео для YouTube
- **DESCRIPTION** - описание (поддерживает переносы строк)
- **TAGS** - теги через запятую
- **CATEGORY** - категория YouTube (обычно "Music")
- **ARTIST** - исполнитель
- **ORIGINAL_VIDEO_ID** - ID исходного видео (для справки)
- **DOWNLOAD_FILENAME** - имя файла при скачивании

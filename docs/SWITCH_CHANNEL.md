# Загрузка на правильный канал YouTube

## Проблема
Видео загружаются на основной канал аккаунта, а нужно на канал "karaoke" (@karaoke-e2t).

## Решение

### Вариант 1: Переключиться на канал при авторизации (рекомендуется)

1. **Удалите старый токен:**
   ```bash
   Remove-Item token.pickle
   ```

2. **Откройте YouTube Studio:**
   - Перейдите: https://studio.youtube.com/
   - В правом верхнем углу нажмите на аватар
   - Выберите канал **"karaoke"** (@karaoke-e2t)
   - Убедитесь, что вы работаете с этим каналом

3. **Запустите скрипт заново:**
   ```bash
   python upload-to-youtube.py
   ```

4. **При авторизации в браузере:**
   - Убедитесь, что вы авторизуетесь от имени канала "karaoke"
   - Разрешите доступ

### Вариант 2: Получить Channel ID и проверить

1. **Запустите скрипт для поиска канала:**
   ```bash
   python get-channel-id.py
   ```

2. **Скопируйте Channel ID** из вывода

3. **Обновите upload-to-youtube.py:**
   - Найдите строку: `CHANNEL_ID = None`
   - Замените на: `CHANNEL_ID = "ВАШ_CHANNEL_ID"`

**Примечание:** YouTube API загружает видео на канал, связанный с авторизованным аккаунтом. Если у вас несколько каналов под одним Google аккаунтом, нужно переключиться на нужный канал в YouTube Studio перед авторизацией.

## Проверка текущего канала

После авторизации можно проверить, на какой канал будет загружаться:

```bash
python get-channel-id.py
```

Скрипт покажет все доступные каналы и их ID.

# Загрузка на канал "karaoke" (@karaoke-e2t)

## Решение

YouTube API загружает видео на канал, который активен в момент авторизации. Нужно переключиться на канал "karaoke" перед авторизацией.

### Шаги:

1. **Удалите старый токен:**
   ```bash
   Remove-Item token.pickle
   ```

2. **Откройте YouTube Studio и переключитесь на канал "karaoke":**
   - Откройте: https://studio.youtube.com/
   - В правом верхнем углу нажмите на **аватар/иконку аккаунта**
   - В выпадающем меню выберите канал **"karaoke"** (@karaoke-e2t)
   - Убедитесь, что в правом верхнем углу отображается именно этот канал

3. **Оставьте YouTube Studio открытым** и запустите скрипт:
   ```bash
   python upload-to-youtube.py
   ```

4. **При авторизации в браузере:**
   - Убедитесь, что вы авторизуетесь от имени канала "karaoke"
   - Разрешите доступ
   - Видео будут загружаться на этот канал

### Важно:

- Токен "запоминает" канал, который был активен при авторизации
- Если вы авторизуетесь с активным каналом "karaoke", все загрузки пойдут на него
- Не переключайтесь на другой канал во время загрузки

### Проверка:

После загрузки первого видео проверьте:
- Зайдите на канал "karaoke" в YouTube Studio
- Убедитесь, что видео появилось там

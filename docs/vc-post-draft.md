## Текст поста

Недавно делал lofi radio, сейчас ещё один музыкальный проект на праздник — сайт с караоке-версиями песен. На этот раз с более активным участием: все видео загружаются на мой YouTube канал, создаются Shorts, всё автоматизировано. Пожалуйста, пользуйтесь.

На самом деле, на данный момент я не вижу явных преимуществ перед обычным YouTube плейлистом — все видео встроены через iframe, тексты песен просто отображаются рядом (хотя в видео уже есть субтитры).

### Зачем тогда нужен сайт?

Честно говоря, на текущем этапе основной причины нет. Но есть несколько вещей, которые меня интересуют:

1. **Статистика и аналитика** — на YouTube я вижу только общую статистику канала, но не понимаю, какие конкретно песни популярны, откуда приходит трафик, как люди используют контент. Сайт дает мне Google Analytics с детальной статистикой по каждой странице.

   На основе этих данных хотел бы формировать топы песен — по количеству посещений, времени на странице, другим метрикам. Это поможет понять, что действительно интересно пользователям, и даст возможность показать популярный контент.

2. **Контроль над трафиком** — трафик идет на мой домен, а не на YouTube. Это дает больше контроля и гибкости в будущем.

3. **Перспективы развития** — в голове есть идеи фич, которые сложно или невозможно сделать в YouTube плейлисте:
   - Персонализированные рекомендации
   - Интеграции с другими сервисами
   - Кастомная логика и функционал
   - А/Б тестирование интерфейса
   - Динамические топы на основе реальных метрик использования

### Что сделано

- 9 песен с караоке-версиями
- Все видео загружены на мой YouTube канал (контроль над контентом)
- Созданы YouTube Shorts для каждой песни
- Единая база данных (songs.json) — из нее генерируются HTML страницы и метаданные
- Автоматизация: можно добавить новую песню одной командой (скачивает с YouTube, загружает на мой канал, создает страницу)

### Эксперименты с автоматизацией

Попутно поэкспериментировал с массовым скачиванием и загрузкой YouTube роликов — все через скрипты. Это было интересным опытом:

**Скачивание видео:**
- Написал скрипт, который скачивает видео с YouTube по списку ссылок
- Автоматически получает человеко-читаемые имена файлов (название песни + исполнитель)
- Объединяет видео и аудио потоки в один файл

**Загрузка на YouTube:**
- Разобрался с YouTube API для автоматической загрузки
- Скрипт создает метаданные (название, описание, теги) и загружает видео
- Все видео загружаются на мой канал с правильными настройками

**Создание YouTube Shorts:**
- Автоматическая конвертация полных видео в Shorts (59 секунд, квадратный формат)
- Скрипт обрезает видео, добавляет padding для защиты текста от обрезки
- Генерирует метаданные со ссылками на полные версии

**Результат:**
Весь процесс автоматизирован. Чтобы добавить новую песню, достаточно дать ссылку — скрипт сам скачает, загрузит на мой канал, создаст Shorts, добавит на сайт. Это сэкономило кучу времени.

Если кому-то интересно — готов поделиться опытом и подходами. Много чего узнал про работу с YouTube API, обработку видео и автоматизацию рутинных задач.

### Технический стек

Простой статический сайт:
- HTML/CSS/JavaScript (фронтенд)
- Python скрипты для автоматизации
- YouTube API для загрузки видео
- FFmpeg для создания Shorts
- Все публикуется на GitHub Pages (бесплатно)

### Планы

Сейчас просто интересно посмотреть на статистику — что люди ищут, какие песни популярны, откуда трафик. На основе этого можно будет сделать выводы и решить, стоит ли развивать дальше или это просто эксперимент.

Если будут реальные пользователи и интересные метрики — подумаю о фичах, которые действительно добавят ценности. Например, автоматические топы песен на основе посещений и других метрик. Это даст реальную ценность — пользователи увидят, что популярно, а я получу обратную связь о том, какой контент интересен.

Если нет трафика и метрик — будет просто эксперимент и опыт в автоматизации работы с YouTube API.

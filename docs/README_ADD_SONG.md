# Добавление новой песни - полный процесс

## Процесс

Скрипт автоматически выполняет полный цикл:
1. ✅ Скачивает видео с YouTube по ссылке
2. ✅ Загружает видео на ваш YouTube канал
3. ✅ Добавляет песню в базу данных с video_id с вашего канала
4. ✅ Генерирует HTML страницу

## Использование

```powershell
python add-song-from-youtube-complete.py "https://www.youtube.com/watch?v=VIDEO_ID"
```

## Пример

```powershell
python add-song-from-youtube-complete.py "https://www.youtube.com/watch?v=sfbCZw_c2Zs"
```

## Что происходит

1. **Извлечение данных:**
   - Скрипт получает информацию о видео
   - Автоматически определяет название песни и исполнителя

2. **Скачивание:**
   - Скачивает видео в папку `downloaded_videos/`

3. **Загрузка на ваш канал:**
   - Загружает видео на ваш YouTube канал
   - Получает новый video_id с вашего канала

4. **Добавление в базу:**
   - Добавляет запись в `songs.json` с video_id с вашего канала
   - Генерирует HTML страницу

## Важно

- ✅ Все видео должны быть загружены на ваш канал
- ✅ Видео на сайте используют video_id с вашего канала (не оригинальные)
- ✅ Это гарантирует, что видео всегда доступны

## Требования

- Python 3
- yt-dlp: `python -m pip install yt-dlp`
- YouTube API настроен (client_secrets.json)
- Канал YouTube для загрузки

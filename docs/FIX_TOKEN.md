# Исправление проблемы с токеном

## Статус
API включен, но токен был создан со старыми правами доступа.

## Решение

Старый токен удален. Теперь нужно:

1. Запустите скрипт заново:
   ```bash
   python upload-to-youtube.py
   ```

2. При запросе авторизации в браузере:
   - Войдите в свой Google аккаунт
   - Разрешите доступ к YouTube (все запрошенные права)
   - Подтвердите

3. После этого токен будет создан заново с правильными правами

## Что произошло

Токен был создан до включения YouTube Data API v3, поэтому у него не было нужных прав. Теперь, когда API включен, нужно создать новый токен.

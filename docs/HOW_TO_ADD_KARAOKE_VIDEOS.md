# Как добавить караоке-версии на YouTube

## Быстрая инструкция

1. **Откройте YouTube** и найдите караоке-версию песни
   - Поиск: `"[название песни] karaoke"`
   - Пример: `"Imagine karaoke"`, `"Let It Be karaoke"`

2. **Популярные караоке-каналы:**
   - Sing King Karaoke
   - Karafun
   - Karaoke Version
   - и другие

3. **Скопируйте ID видео:**
   - Откройте видео на YouTube
   - URL выглядит так: `https://www.youtube.com/watch?v=VIDEO_ID`
   - Скопируйте `VIDEO_ID` (часть после `v=`)

4. **Замените в HTML файле:**
   - Откройте файл песни (например, `public/songs/song1.html`)
   - Найдите строку: `src="https://www.youtube.com/embed/dQw4w9WgXcQ?rel=0"`
   - Замените `dQw4w9WgXcQ` на ваш `VIDEO_ID`

## Пример

**Было:**
```html
<iframe 
    src="https://www.youtube.com/embed/dQw4w9WgXcQ?rel=0" 
    ...
</iframe>
```

**Стало (для Imagine):**
```html
<iframe 
    src="https://www.youtube.com/embed/ВАШ_VIDEO_ID?rel=0" 
    ...
</iframe>
```

## Где найти хорошие караоке-версии

- **YouTube поиск:** `"[песня] karaoke"`
- **Проверьте качество:** видео должно быть четким, звук хорошим
- **Проверьте синхронизацию:** текст в видео должен совпадать с музыкой
- **Проверьте доступность:** видео должно быть доступно для встраивания

## Советы

- Выбирайте версии с четким текстом на экране
- Проверяйте, что видео не заблокировано в вашем регионе
- Некоторые караоке-версии уже имеют подсветку текста в самом видео

---

**Готово!** Теперь на вашем сайте будут показываться караоке-версии песен.

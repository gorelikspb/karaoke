# Проверка включения YouTube Data API v3

## Текущая ошибка
API все еще показывает как не включенный.

## Что нужно сделать

### Шаг 1: Откройте страницу API
Ссылка уже должна открыться в браузере, или откройте вручную:
https://console.developers.google.com/apis/api/youtube.googleapis.com/overview?project=114753552651

### Шаг 2: Проверьте статус
На странице должна быть кнопка:
- Если видите кнопку **"ENABLE"** - нажмите ее
- Если видите **"API ENABLED"** с зеленой галочкой - API включен

### Шаг 3: Подождите
После включения API подождите **2-3 минуты**, чтобы изменения применились на всех серверах Google.

### Шаг 4: Проверьте в списке включенных API
1. Перейдите: https://console.cloud.google.com/apis/dashboard?project=114753552651
2. В разделе "Enabled APIs" должен быть "YouTube Data API v3"
3. Если его нет - включите через Library

### Шаг 5: Попробуйте снова
После 2-3 минут запустите:
```bash
python upload-to-youtube.py
```

## Альтернативный способ включения

1. Откройте: https://console.cloud.google.com/apis/library?project=114753552651
2. Найдите "YouTube Data API v3"
3. Нажмите на него
4. Нажмите кнопку "ENABLE"
5. Подождите 2-3 минуты
